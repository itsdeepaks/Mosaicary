# Task 06 blind-review packet

Review the original frozen prompt, then compare `blind-review/version-a` and `blind-review/version-b`. The folders intentionally do not identify their experimental condition.

Score each version from 1–5 for:

- task fit;
- information hierarchy;
- mobile usability;
- control discoverability;
- density;
- visual coherence;
- repository consistency;
- component reuse;
- accessibility;
- implementation restraint;
- desktop regression risk;
- overall ship readiness.

Then answer: **Which version would you ship: A, B, or tie?**

Do not read `EVIDENCE-REPORT.md` before submitting a review; it includes condition-specific mechanical evidence. Record observations that cite a visible screenshot region or a concrete behavior. This packet deliberately contains no condition mapping.
