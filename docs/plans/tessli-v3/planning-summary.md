## User and task understanding

Tessli needs a complete product realignment before more feature work. It should be a human-curated, AI-native source router: visual and decision-oriented for people, compact and access-oriented for GPT, Claude, Gemini, Codex, and other agents.

## Hierarchy and pattern decisions

Home captures task intent. Browse returns a focused source set. Source Detail becomes a useful source guide with preview, fit, access, limitations, and alternatives. Saved and Boards retain project decisions. JSON, Markdown, and MCP provide compact access guidance from the same canonical data. Live iframe previews are an optional later human enhancement, never the AI access layer.

## Assumptions and open questions

The plan assumes approved static media remains the default preview and remote MCP follows stable local retrieval. No unresolved question blocks the documentation realignment slice.
