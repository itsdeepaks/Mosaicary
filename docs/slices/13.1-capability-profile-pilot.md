# Slice 13.1 — Capability-Profile Pilot for 20 High-Value Resources

Status: **active implementation slice**  
Branch target: `feat/capability-profile-pilot`

## Goal

Profile 20 high-value design resources from the Phase 1 catalogue according to `schemas/resource-intelligence-profile.schema.json`, producing a structured capability dataset with evidence verification, governance rules, and deterministic schema validation, without introducing external web scraping, paid content proxying, or runtime UI changes.

## Acceptance Criteria

- [ ] Create 20 deterministic JSON files under `web/data/intelligence-profiles/`.
- [ ] Every profile validates against `schemas/resource-intelligence-profile.schema.json`.
- [ ] Profiles cover 20 real resources from `web/data/catalogue.json` across 11 key design resource capability categories.
- [ ] Each profile includes verified claims, evidence URLs, explicit unknown states, and governance/persistence policies.
- [ ] Every `resourceId` matches a valid item in `web/data/catalogue.json`.
- [ ] A dedicated test file `web/tests/intelligence-profile-pilot.test.mjs` verifies:
  - schema validity of all 20 profile JSON files;
  - strict mapping between profile `resourceId` and catalogue resources;
  - evidence URL format and verification dates;
  - governance and default persistence policies.
- [ ] `build-slices.md` records `13.1 DONE / 13.2 NEXT`.
- [ ] All CI checks pass (`typecheck`, `lint`, `test`, `catalogue:check`, `build`).

## Exclusions

- No public UI changes or intelligence badges on resource cards/pages.
- No external web scraping, network calls, or third-party API calls.
- No screenshot downloads or binary assets committed.
- No Supabase or authentication changes.
- No native MCP server/client implementation (deferred to Slice 13.5).
