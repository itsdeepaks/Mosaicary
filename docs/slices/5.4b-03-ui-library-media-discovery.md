Status: **implemented — pending pull-request verification**

## Goal

Research the next deterministic batch of 20 pending catalogue resources,
manually review every discovered raster candidate, publish only suitable media,
and record a truthful terminal coverage disposition for every selected resource.

## Acceptance criteria

- the branch starts from refreshed `main` after Slice 5.4b-02;
- the batch is exactly the first 20 remaining pending IDs in catalogue order;
- discovery runs only through the explicit network command and temporary output
  remains ignored;
- every discovered raster and candidate source page is manually inspected before
  production approval;
- approved rows retain stable IDs, source page, raster type, provenance, and
  checked date;
- every selected resource receives a terminal coverage disposition;
- deterministic media, catalogue, test, build, and browser checks pass;
- the complete diff is reviewed for secrets, unsafe URLs, binaries, invented
  claims, and scope creep.

## Exclusions

- no screenshot capture, binary commit, proxy, cache, or object storage;
- no bypass of authentication, anti-bot, rate-limit, or network restrictions;
- no card-layout, Supabase, authentication, dependency, CI, or unrelated data
  changes;
- no fourth discovery batch.
