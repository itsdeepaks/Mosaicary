# Product Plan v2 — Phase 5 / Slice 5.1

Status: **DONE**

## Goal

Create the first real Tessli proof setup for the Online Scope Studio homepage: preserve the current public site as the baseline, define the intended technical-partner brief, retain a reviewable 8–12-source research Board with rejected directions, generate the exact deterministic research pack, and record the baseline workflow before any implementation begins.

## Acceptance criteria

- the proof target is the real public Online Scope Studio homepage at `https://www.onlinescope.in/`;
- the brief distinguishes the observed current-site baseline from the approved future positioning;
- sourced current-site observations are separated from project decisions and open questions;
- one repository proof Board snapshot mirrors the browser-local Board contract without claiming it was uploaded from a user's browser;
- the Board contains 8–12 selected canonical Tessli sources and at least three rejected sources/directions;
- every selected/rejected source ID resolves in the current canonical catalogue;
- source reasons are task-specific and do not describe any provider as universally best;
- missing intelligence, paid/private-source boundaries, licensing, attribution, and live-verification limits remain visible;
- the committed Markdown pack is generated by `createBoardResearchPack`, not hand-authored independently;
- the pack uses an explicit deterministic date and matches regenerated bytes;
- a baseline document records the current workflow, expected measurements, and unknown values without inventing timings or outcome scores;
- the Slice 5.2 handoff identifies the exact candidate-build inputs and exclusions;
- focused proof-fixture, formatter-parity, source-resolution, privacy, and boundary tests pass;
- full CI and release gates pass on the exact final head;
- Slice 5.1 becomes DONE and Slice 5.2 becomes NEXT only after final validation.

- no Online Scope Studio implementation or production-site mutation;
- no Tessli homepage/navigation/playbook redesign;
- no browser screenshots or visual candidate in this slice;

- no new source profile, Verified promotion, live provider verification, scraping, or paid/private content persistence;
- no authentication, cloud, sharing, analytics, forms, moderation, email, dependency, Supabase, credential, or deployment-state change.
