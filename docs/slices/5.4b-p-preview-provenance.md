# Slice 5.4b-p — Open Graph and Twitter preview provenance

Status: **DONE — implementation and exact-head repository gates passed; squash merge pending**

## Goal

Correct the metadata-discovery contract before Batch 6 so Tessli can preserve
whether a reviewed preview came from Open Graph or Twitter metadata instead of
labelling every preview generically as Open Graph.

## Repository finding

The previous parser checked `og:image:secure_url`, `og:image`, `twitter:image`,
and `twitter:image:src`, but returned a plain URL list. The discovery result then
wrote `source: "open-graph"` for the first successful URL even when that URL
came only from Twitter metadata. Both media schemas accepted only `manual` and
`open-graph`, so exact Twitter provenance could not be recorded truthfully.

Starting another reviewed batch with that behavior would have created false
evidence and violated the requirement to report each candidate's actual
metadata source.
