# Product Plan v2 — Phase 4 / Slice 4.2

Status: **IN PROGRESS**

## Goal

Implement the approved `tessli.board-research-pack.v1` contract as a deterministic, browser-local Markdown export from one project Board.

## Acceptance criteria

- one pure formatter accepts an explicit date and never reads the current clock;
- output preserves fixed sections, Board order, bounded profile arrays, unknown-source warnings, UTF-8/LF output, no trailing whitespace, and exactly one final newline;
- validation rejects blank Board name, blank goal, duplicate IDs, zero selected sources, invalid dates, and more than twelve selected sources without silent truncation;
- canonical source facts remain separate from notes, rationale, decisions, and unresolved questions;
- a backward-compatible optional Board audience field is persisted and otherwise exports `Not recorded`;
- Copy Markdown and Download `.md` use the exact same generated bytes;
- controls are labelled, keyboard-operable, focus-visible, responsive, and expose validation/success/failure through accessible status text;
- processing remains local-only with no Board upload, provider fetch, analytics payload, public URL, MCP change, or cloud dependency;
- focused formatter, storage, structural, and browser checks pass;
- the complete diff and exact-head Web CI/release gate are reviewed before merge;
- Phase 4 advances to Slice 4.3 only after this slice is merged.

## Exclusions

- no public source, collection, Board, `.md`, or `.json` route;
- no MCP behavior change;
- no authentication, cloud sync, sharing, collaboration, or analytics;
- no catalogue, profile, evidence, verification, provider, credential, Supabase, dependency, or deployment-state change;
- no OSS proof execution, Pattern Candidate, homepage, navigation, or playbook work.

## Rollback

Remove the formatter, declarations, export controls, tests, Board audience addition, and completion ledger changes. Existing Boards remain readable because the audience field is additive and optional.
