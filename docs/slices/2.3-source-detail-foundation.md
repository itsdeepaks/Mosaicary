# Phase 2 / Slice 2.3 — Source Detail foundation

Status: **DONE**

## Goal

Turn every canonical source record into a useful internal Tessli profile that remains available even when the external provider is unavailable, while preserving truthful progressive coverage.

## Acceptance criteria

- [x] all 295 stable slugs resolve at `/resources/[slug]`;
- [x] Listed profiles provide identity, summary, source type, access, availability, coverage explanation, freshness state, and collection membership without implying enrichment;
- [x] Profiled and future Verified records progressively reveal only supported fields;
- [x] every profile provides browser-local Save and a separate safe external Visit action;
- [x] Add to board is not exposed before Phase 3 Boards exist;
- [x] unavailable providers do not break the internal profile;
- [x] metadata is generated from canonical source data;
- [x] sitemap includes all source-detail URLs;
- [x] source-detail layouts pass the formal responsive and overflow matrices;
- [x] keyboard, focus, semantic heading, description-list, external-link, and status behaviour remain accessible;
- [x] focused tests, full repository checks, production build, and browser/release matrices pass.
