# Phase 2 / Slice 2.3 — Source Detail foundation

Status: **in progress**

## Goal

Turn every canonical source record into a useful internal Tessli profile that remains available even when the external provider is unavailable, while preserving truthful progressive coverage.

## Acceptance criteria

- all 295 stable slugs continue to resolve at `/resources/[slug]`;
- Listed profiles provide identity, summary, source type, access, availability, coverage explanation, freshness state, and collection membership without implying enrichment;
- Profiled and future Verified records progressively reveal only supported fields;
- every profile provides browser-local Save and a separate safe external Visit action;
- Add to board is not exposed before Phase 3 Boards exist;
- unavailable providers do not break the internal profile;
- metadata is generated from canonical source data;
- sitemap includes all source-detail URLs;
- source-detail layouts work at 1440, 1024, 768, 390, and 320px without horizontal overflow;
- keyboard, focus, semantic heading, description-list, external-link, and status behaviour remain accessible;
- focused tests, full repository checks, production build, and browser/release matrices pass.

## Exclusions

- no Similar Sources algorithm;
- no new intelligence profiles or fabricated fields;
- no universal ranking, score, or recommendation claim;
- no project Boards or Add to board action;
- no cloud persistence, authentication, submission, or moderation;
- no provider scraping or live verification;
- no homepage or Browse redesign;
- no dependency, database, Supabase, credential, or deployment change.

## Expected files

- `web/app/resources/[slug]/page.tsx`;
- `web/app/resources/[slug]/source-detail.module.css`;
- `web/components/source-detail/source-actions.tsx`;
- `web/components/source-detail/source-actions.module.css`;
- `web/lib/collections.ts`;
- `web/app/sitemap.ts`;
- focused tests and exact release/browser contracts;
- `build-slices.md` and this evidence document.
