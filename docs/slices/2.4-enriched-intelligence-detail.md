# Phase 2 / Slice 2.4 — Enriched Intelligence Detail

Status: **in review**

## Goal

Expose the existing 20 Profiled intelligence records on Source Detail pages and add explainable Similar Sources without overstating verification or introducing a universal quality ranking.

## Acceptance criteria

- Profiled pages expose recorded capabilities, content objects, platforms, frameworks, integrations, delivery formats, design tools, governance, and evidence.
- Listed pages do not render invented intelligence.
- Existing 275 Listed / 20 Profiled / 0 Verified coverage remains unchanged.
- Profiled pages explicitly state that repository intelligence is not live-provider verification.
- Similar Sources excludes the current source and uses category, source type, and recorded metadata overlap.
- Similar Sources explains the relationship and does not use popularity, trend, rating, or aesthetic scoring.
- Evidence claims retain their recorded source URL in canonical data even when the initial UI summary does not create a new external action.
- No paid/private content is copied into Tessli.
- Type, lint, focused tests, full tests, build, browser, accessibility, release, and complete-diff checks pass.

## Exclusions

- no new intelligence profiles;
- no promotion to Verified;
- no live provider verification;
- no semantic/vector search;
- no universal Compare feature;
- no Browse redesign;
- no Saved/Boards work;
- no authentication, cloud, moderation, or provider credential work;
- no dependency or schema change.
