# Product Plan v2 — Slice 0.2 Execution-Track Realignment

Status: **IN PROGRESS**

## Goal

Correct the active execution model so the blocked Online Scope Studio proof prevents only evidence-dependent work, while independent Source Intelligence work continues toward Tessli's approved coverage targets.

This slice does not change the product direction. It clarifies which work is actually dependent on the Phase 5 human-review artifact.

## Problem

The current ledger says `Slice 5.3 BLOCKED; no independent NEXT slice`. That is too broad.

The Phase 5 proof legitimately blocks:

- the Phase 5 outcome report;
- the evidence-led Tessli homepage;
- Pattern Candidate promotion;
- approved-precedent work;
- public UI-taste claims.

It does not block improving canonical source profiles, evidence quality, freshness handling, website/export/MCP parity, or verification workflow foundations.

The repository currently exposes the truthful baseline:

```text
275 Listed
20 Profiled
0 Verified
```

The approved product direction targets an initial 40–60 Profiled and 20–30 Verified sources. Enrichment remains selected by real workflow value and retrieval usefulness rather than alphabetical order.

## Execution tracks

### Track A — Product foundation

May continue independently when each slice preserves canonical truth and evidence boundaries:

- priority source-profile expansion;
- evidence and freshness improvements;
- verification contract and operator workflow;
- source-detail, representation, and MCP parity for newly enriched data;
- Playbook and Board usability that does not claim evaluated UI judgment.

### Track B — Proof and UI judgment

Remains blocked until its real dependencies are supplied:

```text
5.3 genuine human review
→ 5.4 outcome/evidence report
→ 6.2 evidence-led homepage
→ Phase 7 reviewed Pattern Candidates
→ Phase 10 evidence-backed UI-taste claims
```
