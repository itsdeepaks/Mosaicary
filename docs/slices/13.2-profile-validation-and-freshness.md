# Slice 13.2 — Resource Intelligence Profile Validation, Freshness & Review Tooling

Status: **active implementation slice**  
Branch target: `feat/profile-validation-tooling`

## Goal

Build automated verification tooling for resource intelligence profiles (`web/data/intelligence-profiles/`), checking JSON schema validity (`schemas/resource-intelligence-profile.schema.json`), catalogue linkage consistency, duplicate profile detection, required evidence URL validation, and generating a CLI/CI validation report per `UI-INTELLIGENCE-ROADMAP.md` Slice 13.2.

## Acceptance Criteria

- [ ] Create `web/scripts/check-intelligence-profiles.mjs`:
  - Validates every `.json` profile under `web/data/intelligence-profiles/` against `schemas/resource-intelligence-profile.schema.json`.
  - Verifies that every profile `resource_id` exists in `web/data/catalogue.json`.
  - Asserts uniqueness of profile IDs across the dataset.
  - Validates that evidence URLs use valid `http:`/`https:` protocols.
  - Outputs a deterministic JSON/console summary report with total profiles scanned, total valid, and any schema/linkage violations.
- [ ] Create `web/tests/intelligence-profile-validation.test.mjs` verifying validation rules, error catching for invalid profiles, and report output generation.
- [ ] Add `npm run profiles:check` script to `web/package.json`.
- [ ] All CI checks pass (`typecheck`, `lint`, `test`, `build`).
- [ ] `build-slices.md` records `13.2 DONE / 13.3 NEXT`.

## Exclusions

- No live external network scraping.
- No Supabase or auth changes.
