# Slice 5.4a — Full-Catalogue Media Coverage Architecture

Status: **DONE**

## Goal

Scale the reviewed 5.3 media pilot into a deterministic, resumable research
ledger for all 295 catalogue resources without fetching or approving additional
third-party media in the architecture slice.

## Acceptance criteria

- a schema-validated coverage manifest contains every stable catalogue ID once
  in canonical order;
- approved production media is reconciled as `approved-media` and cannot be
  invented by the coverage ledger;
- unresearched resources remain explicitly `pending`;
- terminal no-media outcomes are `no-suitable-raster`, `blocked`, `failed`, or
  `rejected` and require a checked date;
- generated-letter rendering remains a UI fallback, not research evidence;
- deterministic generation preserves reviewed terminal outcomes;
- validation rejects missing, duplicate, unknown, out-of-order, falsely
  approved, malformed, and stale coverage;
- a network-free selector returns pending resources in deterministic batches of
  1–20 and resumes after a known stable ID;
- the existing candidate queue remains bounded at 50 records and production
  media remains manual-review-only;
- normal tests check both the candidate-review and full-coverage artifacts.

## Exclusions

- no network discovery, DNS lookup, redirect, or remote media request;
- no candidate review or production-media approval;
- no card, fallback, catalogue, collection, MCP, auth, Supabase, or Vercel
  behavior change;
- no screenshot, proxy, cache, object storage, or image binary;
- no dependency or workflow change.

## Security and accessibility

All new commands are repository-only. They perform no network access and cannot
publish candidate media. Existing SSRF, raster-only, provenance, manual review,
and external-media rendering controls remain unchanged. No rendered UI or
accessibility behavior changes.

## Rollback

Revert the slice commit. The approved media source and candidate queue are not
migrated or modified, so no third-party or cloud state requires rollback.
