# Slice 5.4b-01 — reviewed gallery-site media discovery

Status: **implemented — pending pull-request verification**

## Goal

Research the first deterministic batch of 20 pending catalogue resources,
manually review every discovered raster candidate, publish only approved media,
and record a truthful terminal coverage disposition for every resource in the
batch.

## Acceptance criteria

- the branch starts from the refreshed `main` produced by Slice 5.4a;
- the batch is exactly the first 20 pending IDs selected in catalogue order;
- discovery runs only through the explicit network command and temporary output
  remains ignored;
- every discovered preview or favicon is manually inspected before production
  approval;
- approved rows retain stable resource IDs, source page, raster content type,
  provenance, and checked date;
- unresolved resources receive a truthful terminal disposition and checked date;
- no selected resource remains `pending` after review;
- approved-media, candidate-review, coverage, catalogue, test, type, lint, and
  build checks pass;
- the complete diff is reviewed for secrets, unsafe URLs, invented claims,
  scope creep, and accidental binaries.

## Exclusions

- no screenshot capture, binary media commit, proxy, cache, or object storage;
- no bypass of authentication, anti-bot, rate-limit, or private-network controls;
- no changes to card layout or media fallback behavior;
- no Supabase, authentication, catalogue-content, dependency, or CI changes;
- no second discovery batch.
