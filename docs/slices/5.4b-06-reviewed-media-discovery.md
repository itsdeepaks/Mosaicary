## Acceptance criteria

- use `npm run media:batch:select -- --limit 20` against refreshed repository
  truth and record the exact selected IDs;
- fetch only each resource's canonical official page;
- preserve preview priority:
  `og:image:secure_url` → `og:image` → `twitter:image` →
  `twitter:image:src` → favicon → generated mark;
- preserve exact `source` and `sourceProperty` for every discovered preview;
- validate HTTPS, credentials, public DNS, redirects, timeout, HTML size, raster
  MIME type, and response provenance through the existing discovery boundary;
- package discovery JSON and exact candidate raster bytes only as short-lived
  review artifacts; no discovered binary enters Git;
- manually inspect every raster considered for approval and reject ads, login or
  cookie walls, campaign overlays, unrelated/generic imagery, low-information
  banners, broken responses, and ambiguous brand content;
- never bypass authentication, anti-bot controls, paywalls, rate limits, unsafe
  redirects, or private/local networks;
- keep candidate evidence separate from approved production media and require a
  manual reviewed copy action;
- give all twenty selected resources a terminal coverage disposition with a
  checked date and evidence note where required;
- update only reviewed approved media, candidate/review evidence, coverage,
  deterministic generated outputs, focused assertions, progress ledger, and
  this slice note;
- preserve all catalogue IDs, slugs, descriptions, categories, access facts,
  collections, and non-media content;
- run focused validation, formatting, typecheck, lint, the complete test suite,
  media review/coverage/catalogue drift, production build, relevant browser
  interactions, remote-image failure fallback, and horizontal-overflow checks at
  1440, 1024, 768, and 390 pixels;
- complete-diff review finds no secret, screenshot, external binary, dependency,
  proxy/cache/optimizer setting, unrelated UI/auth/database change, or generated
  framework churn;
- open and review one draft PR, pass exact-head CI and Vercel, squash-merge, and
  refresh `main` before Batch 7.

## Exclusions

- no screenshots or screenshot-fallback policy;
- no Google Images, search thumbnails, Pinterest, social repost, stock image,
  third-party image proxy, or unofficial asset;
- no committed third-party raster, SVG, browser profile, discovery artifact, or
  temporary download;
- no unrestricted image proxy, wildcard optimizer, object-storage cache, runtime
  crawler, or network request during normal build/test/CI;
- no more than twenty selected resources;
- no seventh batch in this branch;
- no catalogue fact, UI layout, authentication, Supabase, RLS, form, MCP,
  dependency, or unrelated documentation change.

## Temporary discovery boundary

A one-use branch workflow may run the explicit selector and discovery command and
upload short-lived JSON/raster review artifacts. It must not edit production data
and must be removed before final diff review.

## Rollback

Revert the eventual squash commit. This restores the prior approved-media source,
coverage dispositions, generated catalogue/report outputs, focused assertions,
and ledger without external cleanup because no binary or service state is
created.
