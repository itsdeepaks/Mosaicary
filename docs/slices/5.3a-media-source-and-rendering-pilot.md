# Slice 5.3a — Approved resource-media source and rendering pilot

Status: **active**
Branch: `codex/media-source-pilot`
Base: `main` at `0e66501`

## Goal

Add a small, reviewed set of resource previews to the production catalogue while retaining Tessli's repository-managed catalogue and existing resilient card fallbacks.

## Acceptance criteria

- a schema-validated sidecar is keyed by existing stable resource IDs;
- invalid, duplicate, unknown, non-HTTPS, non-public-host, credentialed, or non-raster media entries fail generation;
- generated catalogue data and validation report include approved media deterministically;
- approved previews render through the existing card in Explore and Saved; the shared collection-card adapter receives the same fields;
- cards remain complete when preview and favicon loading fails;
- no network fetch, image proxy, binary persistence, or broad image optimizer is introduced;
- browser QA covers 1440px, 1024px, 768px, and 390px, including no horizontal overflow and core card interactions.

## Approved pilot coverage

The initial source contains three externally verified Open Graph previews: TOOOLS.design, One Page Love, and Awwwards. This is intentionally narrower than the original resource-card laboratory matrix: the available unmerged draft contained unverified or failing candidates, so expanding its count would turn this source slice into speculative discovery work.

All URLs are remote HTTPS raster images with a review date of 2026-07-31. The existing fallback chain stays unchanged: approved preview, favicon, generated letter mark.

## Exclusions

- no automatic Open Graph or favicon discovery;
- no screenshot generation, remote fetch in CI, proxy/cache, or downloaded third-party images;
- no CSP or remote optimiser policy expansion;
- no changes to the CSV source, public data model beyond optional media fields, visual redesign, or authentication;
- no unverified additions to meet an arbitrary coverage count.

## Expected changes

- `lib_data/resource-media.json` and `schemas/resource-media.schema.json`;
- catalogue generation, report, generated data, and focused tests;
- card data adapters and source selection;
- this contract and the data/media contract.

## Security and accessibility notes

Validation permits only public HTTPS hosts and blocks URL credentials, loopback/local hostnames, and literal IP addresses. Only JPEG, PNG, WebP, and AVIF are approved; SVG is not rendered from remote metadata. Resource cards retain native image loading with `loading="lazy"`, `decoding="async"`, `referrerPolicy="no-referrer"`, an `onError` fallback, semantic external links, separate save buttons, and labelled live save state.

## Deferred follow-up

Slice 5.3b can introduce reviewed discovery and freshness tooling. It requires dedicated SSRF, redirect, content-size, CSP/cache, provenance, and reviewer-workflow decisions.
