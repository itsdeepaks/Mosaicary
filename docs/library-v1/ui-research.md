# Mosaicary Library v1 — visual reference notes

Research was limited to public visual/reference pages on 26 July 2026. It informed interaction and hierarchy patterns only; no screenshots, visual assets, or remote content are copied into Mosaicary.

## Observations adopted

- **Category navigation as a useful index, not decorative chrome.** Public design-resource directories commonly use a left category rail plus dense, compact listings. Mosaicary uses a dynamic category rail on wide screens and retains native selects for small screens. [Design resource directory examples](https://www.wp-query.com/designresourc-es-coleccion-de-recursos-para-disenadores/)
- **Directory cards should expose the decision facts immediately.** Open-source directories foreground name, category, access/credibility signals, and a direct route to the source. Mosaicary’s list items show destination domain, purpose, category, access model, save state, and an explicit new-tab action. [OpenAlternative](https://openalternative.co/), [Open Source Alternatives](https://www.opensourcealternatives.to/)
- **A resource library benefits from dense scanning, not a marketing hero.** The redesign replaces the oversized hero-card treatment with an editorial header, filter bar, two-column index, and direct reading hierarchy. [Contrast directory reference](https://bluedeepart.github.io/codewell-challenges/)

## Deliberately not adopted

- Newsletter capture, advertising, accounts, and submissions.
- Copied logos, screenshots, source thumbnails, popularity metrics, GitHub data, or commercial reference content.
- Infinite scroll and a generic “featured resources” carousel.
