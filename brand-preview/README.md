# Tessli brand preview

A static browser-rendered identity and interface specimen for Tessli. It validates the brand system before the Next.js application build.

## Run locally

```bash
python -m http.server 8000
```

Open `http://127.0.0.1:8000/brand-preview/` when this folder is inside the repository root, or `http://127.0.0.1:8000/` when serving this folder directly.

## What this page validates

- Newsreader Variable display and wordmark weights
- Instrument Sans Variable interface weights
- warm color tokens and contrast roles
- subtle page-grain treatment
- spacing, borders, radii, and elevation
- buttons, fields, tabs, tags, feedback, and focus states
- resource cards with manual-preview, favicon, and letter-mark fallbacks
- responsive hero composition with truthful product facts
- approved Explore, Collections, Saved, and Full Reference art direction

This preview is not the production application and contains no authentication, persistence, database, or submission backend.
