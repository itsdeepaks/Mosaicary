## Access labels

- **Free:** the core resource can be browsed or used without payment.
- **Open source:** free to use and source-available; the specific software license still applies.
- **Freemium:** useful free access exists, while advanced features, larger libraries, exports, or team features may require payment.
- **Paid:** payment is required for the main value of the resource.
- **Free trial:** temporary free access is offered before payment.
